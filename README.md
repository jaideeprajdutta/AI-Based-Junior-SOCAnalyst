# AI-Based Junior SOC Analyst

An intelligent security operations center (SOC) assistant that leverages AI to analyze logs, detect anomalies, and provide remediation suggestions.

## Features
- Log Analysis
- Threat Intelligence Integration
- Automated Incident Response Suggestions

## Tech Stack
- **Backend:** Python (FastAPI)
- **AI Engine:** Google Gemini
- **Frontend:** React (Optional)

## Getting Started
1. Install dependencies: `pip install -r requirements.txt`
2. Run the application: `uvicorn main:app --reload`
